## Proposed fixes

5b (only non-confirmed item). Minimal wording, keeping voice and length:

Current: "Moving the instruction from the user prompt to the system prompt raised resistance for every model but one, with o3 going from 1.7 to 22.5 percent and Grok 4 from 72.2 to 97.3 percent."

Option A (closest to the paper's own phrasing): "Moving the instruction from the user prompt to the system prompt raised resistance for most models, with gpt-oss-120b the one exception, o3 going from 1.7 to 22.5 percent and Grok 4 from 72.2 to 97.3 percent."

Option B (precise to the data): "Moving the instruction from the user prompt to the system prompt raised resistance for every model that resisted at all except gpt-oss-120b, with o3 going from 1.7 to 22.5 percent and Grok 4 from 72.2 to 97.3 percent."

Neither changes what the section claims; line 119's "worked less reliably" is unaffected.

Optional (not an error): if the author would rather cite only the paper, Figure 8's own labels are o3 2 -> 23 percent and Grok 4 72 -> 97 percent, which would let the provenance sentence ("Those per-model figures come from ...") be dropped.
